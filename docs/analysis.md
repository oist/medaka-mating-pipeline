# Analysis

Define behavioral primitives (events) first, then aggregate into metrics.

## Behavioral primitives (examples)

- Courtship: approach, follow, lateral display, quiver
- Aggression: chase, displacement, bite/strike proxy
- Preference: proximity, orientation, time-in-zone

## Outputs

Prefer writing results under `runs/<date>/<trial_id>/...` along with a copy of configs.
