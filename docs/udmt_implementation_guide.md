# UDMT — Developer Implementation Guide

Source of truth: clone `Z:\StephensU\medaka\udmt\UDMT` of `github.com/cabooster/UDMT`, version **1.1.0** (`udmt/version.py:8`). (Originally written against a local clone at `C:\udmt_analysis\UDMT`, since consolidated onto Z:.) Every claim below is grounded in inspected files with `file:line` references. Items not verifiable in code are marked **[ASSUMPTION]**, **[Described-in-paper]**, or **[NOT-FOUND]**.

UDMT = *Unsupervised Deep transfer learning for Multi-animal Tracking*. Concretely, the repo is an embedded fork of the **TrDiMP** tracker (PyTracking/LTR framework) wrapped in a PySide6 GUI, with (a) a SEEM/X-Decoder + SAM + XMem front-end for first-frame instance masks, (b) an **unsupervised forward–backward cycle-consistency** fine-tuning loss, and (c) a **mask-centroid localization refinement** plus a **DTW-triggered backward ID-correction** module that is **appearance-light** (no persistent individual-appearance model — the template/score-map cues are still appearance-derived).

> **Framing caveat (added after review):** treat this guide as a strong engineering *hypothesis*, not a finished porting spec. (1) Training is **self-training + forward/backward consistency**, not raw-video self-supervision — it still needs first-frame masks, a pretrained TrDiMP, pseudo-boxes, and generated labels. (2) The system is **appearance-light**, not appearance-free. (3) The code is heuristic and constant-laden — port the **principles, not the thresholds**. (4) Port onto **2D top-cam + projected-3D first**, not pure 3D geometry (UDMT's trigger relies on 2D overlap / foreground / response-maps; pure-3D has different failure signals). (5) The lesson vs idtracker.ai is *don't rely on appearance alone* — appearance can still be a low-weight cue. Re-validate every claim on medaka data before production use.

## 1. Executive summary

- **What it does:** tracks N visually-similar animals in a single-camera 2D video, outputting per-animal centroid trajectories (`.npy`, shape `(num_animals, num_frames, 2)`).
- **What is "unsupervised":** no per-frame manual annotation. Two places realize this: (1) **pseudo-labels** are generated by running a *pretrained* TrDiMP over the video (seeded by first-frame masks) with a trajectory-level backward swap-repair; (2) the network is **fine-tuned with a forward→backward cycle-consistency loss** (track A→B, then B→A, penalize landing back on the original box) — `ltr/actors/tracking.py`. No ground-truth boxes enter the loss (`bb_ce` weight = 0).
- **User input still required:** click the center of each animal in frame 1 (or accept SEEM auto-detection), set animal count, and set a handful of GUI params (resize, epochs, batch). The first-frame step is inherently GUI/click-driven.
- **Main architectural components:** SEEM (first-frame masks) → XMem+SAM (interactive init + foreground masks) → TrDiMP "ST-Net" (ResNet-50 + transformer + DiMP discriminative filter) → mask-centroid refinement → backward ID-correction → post-filter + visualization.

  -> analyze_videos:

## 4. Model architecture — "ST-Net" = TrDiMP

The "Spatiotemporal Transformer Network" is a **TrDiMP**: ResNet-50 backbone → classification feature extractor → a transformer (encoder over the template set + decoder cross-attention) → a **DiMP discriminative correlation filter** optimized by steepest-descent, plus an AtomIoUNet used only at inference for box size.

| Component | File:line | Class/fn | Train/Infer | Notes |
|---|---|---|---|---|
| Backbone | `ltr/models/tracking/dimpnet.py:120` | ResNet-50 (`backbone/resnet.py:284`) | both | clf feat from `layer3` (256-ch). Frozen `conv1,bn1,layer1,layer2`. |
| Clf feature extractor | `dimpnet.py:133` | `clf_features.residual_bottleneck(out_dim=512)` | both | →`(B,512,22,22)` @352² input. |
| Template vs search | `target_classifier/linear_filter.py:63-70` | `LinearFilter.forward` | train | both pass same extractor; encoder consumes template, decoder consumes search. |
| Transformer | `target_classifier/transformer.py:16` | `Transformer(d_model=512,nhead=1,layers=1)` | both | encoder = self-attn over **all template frames' spatial tokens jointly** (the "temporal" mixing, `transformer.py:95-96`); decoder = target-aware cross-attn (`memory*pos`, `:154`). |
| Attention primitive | `target_classifier/multihead_attention.py:9,31` | `MultiheadAttention`/`RelationUnit` | both | 1 head, shared WK for q&k, softmax temp 30. |
| DiMP filter (loc. head) | `linear_filter.py:9,96-123` | `LinearFilter` | both | correlation filter → score/response map (6 maps, one per optimizer iterate). |
| Filter optimizer | `dimpnet.py:143`; `target_classifier/optimizer.py:17` | `DiMPSteepestDescentGN(num_iter=5)` | both | steepest-descent + Gauss-Newton unroll. |
| Box head (IoUNet) | `dimpnet.py:160` | `AtomIoUNet` | **infer only** | `DiMPnet.forward` comments out bb_regressor; training optimizes classifier only (`bb_ce` weight 0). |
| Template update | `pytracking/tracker/trdimp/trdimp.py:374-391` | (commented out) | infer | online memory + DiMP `update_classifier` are **disabled** → memory fixed after init. |
| Ckpt save / load | `ltr/trainers/base_trainer.py:137`; `ltr/admin/loading.py:34` | `save_checkpoint`/`load_network` | both | `DiMPnet_ep%04d.pth.tar`; rebuild from stored `constructor`, `strict=False`. |

One inference step (`trdimp.py:272` `track`): crop search patch → ResNet layer3 → clf bottleneck `x_clf(1,512,22,22)` → transformer decoder vs fixed `transformer_memory` → DiMP filter correlation → `localize_target` (max2d peak) → `refine_target_box` (AtomIoUNet) for size.

## 5. Training implementation

**Pseudo-label generation** (`create_training_dataset.py:249`): extract ≤**2000** frames (`:229`), resize **0.8** (`:73`), downsample **1** (default no-op, `:88`; the `int(1/rate)` arithmetic is inverted vs the tooltip **[ASSUMPTION]**). Run **pretrained** `pretrained/trdimp_net_ep.pth.tar` (`:291`) over frames with a 3×3 sweep, init boxes from `start_pos_array.txt × resize` (`run_tracker.py:63-70`). Best trajectories → mean-filtered (size 5) `x,y,w,h` label files (`convert_to_train_set.py:30-88`) at `training-datasets/<v>/label/`; frames at `…/img/%05d.jpg`.

**Trajectory-level backward swap repair** during pseudo-labeling (`evaluation/single_object_track.py:339` `single_compensate`): on a detected crossing, re-track backward and vote on identity (`match_compensate_target`, `:145-335`).

**Network loss — forward-backward cycle-consistency [Implemented-in-code]** (`ltr/actors/tracking.py:383`, `unsupervised_flag=True` `:408`):
1. Forward: `target_scores = net(train, test, train_bb, train_label)` (`:399`).
2. From the forward response peak build a predicted test box + Gaussian label (`localize_target` `:436`).
3. Backward (swapped): `net(train=test_images, test=train_images, train_bb=predict_test_anno, train_label=predict_test_label)` (`:454-457`).
4. Loss = `LBHinge` of backward score maps vs a Gaussian regenerated from the **original** train box (`:492-510`). Weighted `100·final + 100·init + (400/(K-2))·Σ intermediate`.

`LBHinge` (`models/loss/target_classification.py:6`): `L = mean[ bg: max(S,0)² ; fg: (S−Y)² ]`, threshold τ=0.05. `bb_ce` (KLRegression) weight **0** (`transformer_dimp.py:132`).

**Optimization** (`train_settings/dimp/transformer_dimp.py`): Adam, base lr 2e-4 (transformer 1e-3, backbone layer3 2e-5), `StepLR(15,γ=0.2)`, batch **8**, **20** epochs default, `samples_per_epoch=5000`. Warm-start loads pretrained TrDiMP but **drops `*.filter*` keys** (fresh classifier) and does not restore optimizer state (`base_trainer.py:231-243`). Keeps **3** latest checkpoints; inference picks the **latest epoch** (`analyze_videos.py:84-128`). **Workspace dir `models/<video>` is wiped at training start** (`admin/local.py:22-36`).

**Datasets:** got10k/lasot/coco are **legacy/unused**; `Got10k` is repurposed (`dataset/got10k_revised.py`) to read `training-datasets/<video>/{img,label}` via `admin/local.py:7` repointing `got10k_dir`.

## 6. Inference implementation

`analyze_videos.py:529` → `extract_whole_frames` → `run_tracking` twice (tune `status=2`, final `status=3`). Engine `pytracking/tracker/trdimp/trdimp.py`, one tracker **per animal** in parallel with a shared **batched backbone** (`extract_backbone_parallel`, `trdimp.py:148`) + a separate `tracker_compensate` for backward correction (`tracker_multi.py:268-274`).

- **Confidence:** `localize_advanced` flags via `target_not_found_threshold=0.25`, `distractor_threshold=0.8`, `hard_negative_threshold=0.5` (`parameter/trdimp/trdimp.py:59-61`).
- **Localization refinement (mask-centroid snapping):** uses the **precomputed XMem foreground masks** `tmp/<v>/masks/%07d.png` (not live SAM). For each animal, look up the connected-component at the predicted point; if its area ∈ `[0.5,1.2]×area_in_first_frame`, replace position with the blob **centroid** (`missing_object_detect.py:252` `refine_pos`). Then `tracker.update_post` re-anchors the model to the refined position (`tracker_multi.py:630`).
- **ID correction (appearance-light) [Implemented-in-code]:** DTW trajectory-coincidence (`dtw<0.8`) + inter-animal distance (`<0.8×box`) → detect an orphan foreground blob → **backward re-track** with `tracker_compensate` → **3-cue majority vote** (velocity-std, max/mean-speed ratio, min response-score) → overwrite the wrong animal's trajectory from the crossing frame + reinit its tracker (`single_object_track.py:145-565`, `tracker_multi.py:709-880`).

**Outputs:** per-animal `tracking-results/<v>/…/<seq>_<id>_new.txt`; final `<v>-whole-filter<N>.npy` `(num_animals,num_frames,2)` + `.mp4` (`filter_and_save.py`); tuning `evaluation_metric_for_{train,test}.json`; `cross_timepoints.json`.

## 7. Key algorithms (pseudocode, from real code)

**(a) Training-dataset creation**
```
require masks/ (first-frame SEEM/XMem instance masks) and >2000 frames
extract <=2000 jpgs (resize 0.8) -> training-datasets/<v>/img
params = {model: pretrained/trdimp_net_ep.pth.tar, frame_num:2000,
          search_scale:[1.5,2,2.5], target_sz_bias:[-.1,0,.1], status:1}
run_tracking(params):
    init boxes = start_pos_array.txt * resize
    for (bias, scale) in sweep: forward TrDiMP; on crossing: single_compensate (backward vote)
best = argmin(evaluation_metric_for_train.json)
create_train_label(best) -> mean-filter(x,y) -> label/<v>_<id>_new.txt  (x,y,w,h)
```

**(b) Auto parameter tuning** (`analyze_videos.py:556`, `tracker_multi.py`)
```
reset global minima (correct, miss, loss = +inf)
for bias in [-.1,0,.1]:
  for scale in [1.5,2,2.5]:
    track first 4000 frames (status=2)
    if early not_found/miss too high -> abort
    if correct/loss/miss > best-so-far -> prune
    append {bias,scale,correct,miss,loss,time} to evaluation_metric_for_test.json
    update minima
best = test.json[-1]            # last surviving config
final full-length track with best (status=3)
```

**(c) Main tracking loop** (`trdimp.py`, `tracker_multi.py:530`)
```
for frame in frames[1:]:
  patches = [tracker[i].extract_patch(frame) for i in animals]
  feats = backbone(stack(patches))                          # batched, one pass
  for i in animals:
     x = transformer_decoder(clf_feat(feats[i]), memory_i)  # fixed template memory
     score = correlate(filter_i, x); pos_i, flag = localize_advanced(score)
  if frame>10: pos = refine_pos(pos, foreground_mask[frame])  # centroid snap
  for i: tracker[i].update_post(flag_i, pos_i)               # re-anchor + (disabled) online update
  every judgement_gap: detect+correct ID swaps (see d)
```

**(d) Localization refinement + ID/backward correction**
```
refine_pos(pred, mask):
   blobs = connectedComponents(binarize(mask))   # area gating [0.4,1.2]x first-frame area
   for each animal: if blob at pred has area in [0.5,1.2]x: pos <- blob centroid

every judgement_gap frames, for each pair (a,b):
   if DTW(traj_a[-T:],traj_b[-T:])<0.8 and mean_dist(a,b,last10)<0.8*box:   # coincidence
      orphan = nth_largest_free_blob(mask)                                  # separated target
      if dist(orphan,a)>0.8box and dist(orphan,b)>0.8box:
         comp = backward_track(tracker_compensate, from f down to crossing)
         votes = 0
         votes[argmax velocity_std] += 1
         votes[argmax max_speed/mean_speed] += 1
         votes[argmin min_response_score] += 1
         wrong = argmax(votes)
         traj[wrong][crossing:] = reversed(comp); reinit tracker[wrong]
         correct_cross_times += 1
   if swap attempts exceed limit: snap wrong to nearest blob; reinit (loss recovery)
```

## 8. Extension points (and what to borrow for the medaka 3D pipeline)

**Where to adapt UDMT to a new species / camera / output format:**
- **Animal count & init:** `start_pos_array.txt` (centroids) + `num_objects` (`xmem/interactive_demo.py`). Replace the SEEM/SAM front-end with any detector that writes a binary `0000000.png` + centroid list.
- **Output format:** `filter_and_save.py::post_process_results` (box→center, filter, `.npy`). Hook here to emit a custom CSV / per-frame schema.
- **Foreground source for refinement:** `missing_object_detect.py` reads `masks/%07d.png`. Swap in any per-frame foreground/segmentation source (e.g. SLEAP-derived masks).
- **Integrate external segmentation/pose/3D:** the cleanest insertion points are (1) replace the front-end masks, (2) replace `refine_pos`'s blob source, (3) consume the `.npy` tracks downstream.

**The transferable idea for our problem (medaka, weak appearance silhouette ≈ 0.73):** UDMT's ID-correction is **appearance-light** — no persistent individual-appearance model (unlike idtracker.ai), though it still uses the tracker's template/score-map (appearance-derived) alongside trajectory coincidence (DTW), inter-animal distance, orphan-blob detection, and backward re-tracking, decided by a **multi-cue motion/confidence vote**. The lesson vs idtracker.ai is not "appearance is useless" but **"don't rely on appearance alone"**: in our weak-appearance regime appearance becomes one *low-weight* cue among motion/geometry cues, not the primary key. **Port the principles, not the thresholds** — the UDMT code is heuristic and full of species/FPS constants (Section 9); adopt the *structure* (coincidence trigger → backward repair → multi-cue vote → conservative apply) and re-derive every threshold on medaka data.

Proposed medaka repair module (conservative, reversible, **test-first**):
1. **Trigger** on **top-camera 2D tracks AND projected-3D tracks** (not pure 3D geometry first — UDMT's trigger leans on 2D overlap/foreground/response-maps; pure-3D has different failure signals). Trigger = close-contact (inter-animal distance < ~one body length) + DTW/velocity coincidence over the window.
2. **Candidate** for the separated target from a missing/unmatched mask (SAM2/Detectron2 or foreground residual), reusing the existing seg-ID tooling.
3. **Backward repair** over the crossing window only.
4. **Vote with medaka-native cues**, each low-weight: 2D speed spike, 3D speed spike, reprojection residual, bind score, SLEAP confidence, mask quality (optionally the weak appearance signal as one more low-weight cue).
5. **Require a vote margin**; below it, emit a **review flag**, not a guessed repair — never silently overwrite.
6. **Validate against hard crossing windows** (the K_1_2 crossings we already have montages for) and score *before* any change touches production 3D IDs. Output a refined/repaired `top_cam.tracks.csv` for `--bind-top-id` plus a flags/diagnostics table.

This stays in-codebase (extends the `UDMT/` adapter), GUI/CUDA-free, appearance-light — and is explicitly a **hypothesis to be measured on hard crossings**, not a guaranteed win.

## 9. Implementation cautions

- **Hard-coded constants:** 2000 training frames, resize 0.8, sweep grids `[1.5,2,2.5]×[-.1,0,.1]`, thresholds (`dtw<0.8`, distance `0.8×box`, area `[0.5,1.2]×`, `not_found 0.25`/`distractor 0.8`/`hard_neg 0.5`), backward window 100–270 frames by fps, `kernel=area/400` capped 8. Most live as GUI defaults/literals, **not** persisted to `config.yaml` (only `is_concave` is read back).
- **Hidden assumptions:** all animals roughly equal size unless `animal_species==3` auto-detected (≥3× area ratio); foreground masks exist and are reliable for the whole video; the param search's "best = last surviving JSON entry" relies on pruning order, not an explicit argmin (`analyze_videos.py:568`); `downsample` arithmetic is inverted at default.
- **Failure modes:** strong on smooth motion / clean foreground; degrades when fish interact (motion ambiguous), when masks are poor (refinement snaps to wrong blob), or in heavy crowding. Online model update is disabled → no appearance drift adaptation after init.
- **Bottlenecks / GPU memory:** backbone batched across animals (good); per-pair backward retracks (up to 270 frames) are the main cost at crossings; SEEM Focal-L + MSDA CUDA op + XMem + SAM are VRAM-heavy (front-end). Training warm-starts a full TrDiMP.
- **Environment fragility:** Linux strongly recommended (README explicitly "not recommended" for Windows); Python 3.8, PyTorch pinned to CUDA (2.1.1/cu121 or 1.11/cu113); two custom builds (MSDA CUDA op, PrRoIPooling); RTX-4090 needs a `cpp_extension.py` arch patch. Likely painful on Blackwell + Windows.

## 10. Suggested refactoring plan (if scripting UDMT itself)

- **Decouple logic from GUI:** `run_tracking` takes Qt widget handles in its param dict (`analyze_videos.py:547`); extract a pure-Python `track_video(params)` that accepts an optional display callback (default no-op) so it runs headless. Same for `train_network`/`create_training_dataset`.
- **Centralize params:** move the hard-coded constants into the per-project `config.yaml` (or a `tracking.toml`) so runs are reproducible and tunable without code edits.
- **Module boundaries:** (1) front-end masks (SEEM/SAM/XMem) → `init_masks(video) -> (mask0.png, centroids)`; (2) pseudo-label `make_dataset(video, masks)`; (3) `train(dataset)`; (4) `track(video, model, masks)`; (5) `postprocess(tracks)`. Each as a callable with typed inputs/outputs.
- **Tests:** smoke-test `refine_pos` and `match_compensate_target` on synthetic blobs/trajectories (pure NumPy, no GPU); a tiny end-to-end test on a few-frame clip with a stub model. Keep file paths compatible with the existing project tree.
- **Minimal, reversible:** wrap, don't rewrite — preserve current GUI behavior; the headless functions call the same core.
