#
# ========== 一步安装（推荐） ==========
# 1) 若尚未安装 uv，PowerShell 执行：
#      irm https://astral.sh/uv/install.ps1 | iex
#    然后关闭并重新打开终端。
#
# 2) 在项目根目录执行（创建 .venv 并安装，含 PyTorch CUDA 13.0 + SLEAP）：
#
#      uv sync --python 3.11
#
# 3) 若只想装 SLEAP 命令行（不建项目 venv），可用官方方式：
#
#      uv tool install sleap-nn[torch] --torch-backend auto
#
#     （auto 会按本机 GPU/CUDA 自动选 PyTorch 后端，适合 RTX 4060 + CUDA 13.0）
#
# 仅 CPU（不用 GPU）时可选：
#   uv sync --python 3.11
#   uv pip install torch torchvision torchaudio --index-url https://download.pytorch.org/whl/cpu
#   uv pip install -e ".[dev,sleap]"
#
# 或使用 pip（需先创建并激活 venv）：
#   pip install -e ".[dev,sleap]"
# 本机 GPU：pip install torch torchvision torchaudio --index-url https://download.pytorch.org/whl/cu130
# 再：pip install -e ".[dev,sleap]"
#
