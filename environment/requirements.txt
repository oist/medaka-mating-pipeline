# Medaka Mating Pipeline - dependency reference
# Purpose: calibration, SLEAP tracking, 3D reconstruction, behavior analysis,
# and notebooks.
# Current local setup: Python 3.11, NVIDIA RTX 4060, CUDA 13.0.
# PyTorch uses the cu130 index configured in pyproject.toml.
#
# ========== One-step install (recommended) ==========
# 1) If uv is not installed yet, run this once in PowerShell:
#      irm https://astral.sh/uv/install.ps1 | iex
#    Then close and reopen the terminal.
#
# 2) From the project root, create `.venv` and install the project,
#    including PyTorch CUDA 13.0 and SLEAP:
#
#      uv sync --python 3.11
#
# 3) If you only want the SLEAP CLI without creating the project venv:
#
#      uv tool install sleap-nn[torch] --torch-backend auto
#
#    `auto` chooses the PyTorch backend based on the local GPU/CUDA setup.
#
# CPU-only option:
#   uv sync --python 3.11
#   uv pip install torch torchvision torchaudio --index-url https://download.pytorch.org/whl/cpu
#   uv pip install -e ".[dev,sleap]"
#
# Or use pip after creating and activating a virtual environment:
#   pip install -e ".[dev,sleap]"
# For the current GPU setup:
#   pip install torch torchvision torchaudio --index-url https://download.pytorch.org/whl/cu130
#   pip install -e ".[dev,sleap]"
#
