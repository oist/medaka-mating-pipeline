# 青鳉配对行为的"机动状态"分析：按 O'Shaughnessy et al. (PRX Life 2024) 的方法

日期：2026-11-08　　数据：K 组、P 组各 3 次实验（1 雌 F + 2 雄 M1、M2，3D 三节点：嘴、胸鳍点、尾）

---

## 1. 目的

用论文的无监督方法（配对状态 → 微状态 → 滞后 τ 转移矩阵 → Infomap 聚类），看能否从 3D 轨迹中**把 quick circle（求偶）和 attack（攻击）与其他帧分开**。

- 标注（BORIS，只在聚类之后用于评估）：
  - `qc` = quick circle + incomplete qc + Courtship；
  - `att` = attack + attempted att + Dash；
  - `wrap`；
  - 其余行为（follow、chase、approach 等）记为 `unknown`，不计入评估。
- 训练：K_1_1、K_1_2、P_1_1、P_1_2；测试：K_1_3、P_1_3。测试视频和训练视频是同一批鱼，不是新个体。
- 两个分析单元：
  - **FM**：雌鱼永远是 fish a，FM1 和 FM2 合并；
  - **MM**：M1M2 和 M2M1 合并（对称化）。

## 2. 论文流程和我的实现

论文：O'Shaughnessy, Izawa, Masai, Shaevitz, Stephens, *Dynamics of Dominance in Interacting Zebrafish*, PRX Life 2, 043006 (2024)。对象是一对雄性斑马鱼打斗，100 fps，22 次实验（用 18 次），约 1600 万帧。

| 论文的步骤（原文位置） | 论文的具体做法 | 我做的 | 区别 |
|---|---|---|---|
| 轨迹预处理（Methods P） | 去掉 head-pec > 1.2 cm、pec-tail > 2.5 cm 的骨架；≤ 5 帧的缺口线性插值；Savitzky-Golay 平滑（二阶，9 帧 = 0.09 s） | 用人工审核后的 3D 坐标；v1–v3 不平滑；v4 做不平滑和 11 帧（0.066 s）两版 | 论文先平滑；我们的审核屏蔽帧不插值 |
| 共转坐标系 + PCA（Fig. 2a、S4、S5） | 原点 = 两个 pec 中点，X' = 指向对方 pec，14 维做 PCA：PC1 = 水平距离，PC2 = 上下距离，PC3–8 = 朝向和俯仰，PC9–14 = 姿态 | 11-07：同样的共转坐标、14 维 PCA | **我们的 PC1 是上下距离（约 58%）**，论文是水平距离 |
| 自相关（Fig. 2b） | 距离最慢，朝向较快，姿态最快 → 只保留距离和朝向 | 每个状态变量的 ACF | 相同 |
| 配对状态（Fig. 2c） | (D_PP, θ_W, θ_L)：3D pec 距离 + 两条鱼的水平朝向；**明确去掉 Δz 和俯仰**（打斗基本在同一水平面，Fig. S6；俯仰集中在 0 附近，Fig. S7） | v1–v3：(D_xy, Δz, θ_a, θ_b)；v3 加速度；v4 加绕圈速度、接近速度、转向、弯曲、俯仰 | **保留了 Δz**（青鳉上下错开是最大的变化）；用水平距离；加了动态变量 |
| 分格（Methods T） | 每维 20 等分：D 0–20 cm（1 cm 一格），θ 18° 一格 → 8000 个微状态 | v1 12672、v2 2048、v3 16129、v4 14337 | 加了 contact 状态，不丢帧 |
| 转移矩阵 + Infomap（Methods U） | τ = 10 帧（0.1 s）；python-igraph Infomap，trials = 500；**56 个簇** | 相同的 igraph Infomap，200–500 次 | 我们的簇多得多（见第 6 节） |
| 选 τ（Methods V，Fig. S11a） | 最大簇体积比例随 τ 变化，在 τ = 12 帧处突然跳变（近距离的簇全部合并）→ 取跳变前的 τ = 10 | 相同规则（"论文规则"），另加训练集留一实验 AUC | 新增 LOEO 标准 |
| 找出行为时段（Fig. 3、S8） | **先无监督地找出打斗时段**：1 分钟窗口内的 P(D, θ₁+θ₂, \|θ₁−θ₂\|)，用 Jensen-Shannon 距离做层次聚类 | 用 BORIS 人工标注的 qc / att / wrap | 我们用人工标注 |
| 选出"机动"（Fig. S11b） | 56 个簇按"在打斗时段出现的频率"排序，前 16 个覆盖 95% 的打斗帧 → 合并左右对称 → **10 种机动** | 集中度分析（`20261108_cluster_concentration_v2v3v4`），按 qc / att 帧排序 | 相同思路；另加纯度 |
| 解释机动（Fig. 5、S12、Methods W） | 每种机动在 (D, θ_W, θ_L) 中的位置；停留时间分布（近似指数，均值约 0.4 s）；以该机动为条件的整体转速 φ̇ | 每个簇的状态空间占用图、平均停留时间 | 我们没有画停留时间分布和 φ̇ |
| 长时间尺度（Fig. 6、7） | 行为时间线（ethogram）；1 分钟 / 30 秒滑动窗口内各机动的出现概率，对齐打斗开始和结束 | 各实验 / 配对的簇使用比例；测试视频时间线 | 我们没有做窗口概率随时间的变化 |
| —（论文没有） | — | 用 BORIS 给簇打分：P(行为 \| 簇) → 平滑 → 训练集定阈值 → **测试视频评估**；和"只用距离"的基线比较 | **新增**：有监督评估、训练 / 测试划分、距离基线 |

### 5.2 能否分开 qc、att（新增部分，测试视频 K_1_3、P_1_3）

v3 结果，和"只用 3D 胸鳍距离"的基线比较：

| | v3 簇方法 | 只用距离 |
|---|---|---|
| FM qc：AUC | 0.94 | 0.92 |
| FM qc：AP（正例比例 0.016） | 0.34–0.47 | 0.11 |
| FM qc：阈值下精确率 / 召回率 | 0.42–0.50 / 0.43–0.48 | 0.13 / 0.46 |
| FM qc：找到的 bout（共 66） | 28–39 | 27 |
| MM att（τ=3）：AUC | 0.97 | 0.925 |
| MM att：精确率 / 召回率 | 0.07 / 0.40 | 0.02 / 0.27 |
| MM att：找到的 bout（共 108） | 52 | 28 |
| FM att（7 个 bout） | 检测不到 | 检测不到 |
| FM wrap：AUC / 精确率 | 0.94 / 约 0.05 | **0.98 / 0.39** |

- **v2 时簇方法和距离基线差不多**（qc 0.94 vs 0.90；att 0.92 vs 0.95）。**v3 加入速度后，簇方法在 qc 和 MM att 上明显好于距离**，主要体现在精确率（qc 误报约为距离方法的 1/4）。
- 逐视频：
  - K_1_3 FM2 qc：精确率 0.46、召回率 0.45，每分钟 1.6 次误报（距离方法每分钟 5 次）；
  - P_1_3 M1M2 att：精确率 0.31、召回率 0.43；
  - K_1_3 的 att 误报很多（精确率 0.03），可能因为 K 组的 chase 被算作 unknown。
- **哪条雄鱼求偶更多（FM1 vs FM2）**：两个测试视频 × 5 个 τ，共 10 种组合，方向全部正确。但比例被压扁了，例如真实 1 : 14，预测约 1 : 4。
- **最短时长筛选**（时长 = 训练集 qc bout 长度的第 5 百分位 = 0.90 s）：精确率上升，召回率下降。例如 P_1_3 FM2：精确率 0.48 → 0.73，召回率 0.56 → 0.39。
- **误报片段**：FM 在 τ=30 下的 92 段误报中，86 段这对鱼在 BORIS 里没有任何标注。qc 和 att 在 BORIS 中没有漏标，所以这些都是真误报，上面的精确率就是真实精确率（误报片段的小视频已导出，可用来看误报是什么样的游动）。

### 5.3 τ 的选择

| | 论文规则 τ | LOEO 最佳 τ |
|---|---|---|
| v2 | FM 100 帧（0.60 s），MM 70 帧（0.42 s） | FM qc 5、wrap 20；MM att 1 |
| v3 | FM 50（0.30 s），MM 14（0.08 s） | FM qc 30、att 3、wrap 7；MM att 3 |

- att 很短（多数 < 0.1 s），在小 τ 下最好分开，τ 越大越差。论文规则选出的 τ 偏大，不适合 att。
- qc 在大范围的 τ 下表现都差不多（LOEO AUC 0.91–0.92）。

### 5.4 qc / att 落在哪些簇里（集中度和纯度，对应论文 Fig. S11b）

做法同论文 Fig. S11b：簇按训练集里该行为的帧数排序，看前几个簇能覆盖多少行为帧；另加论文没有的纯度。测试集沿用训练集的顺序。文件夹 `20261108_cluster_concentration_v2v3v4`。

| | 簇总数 | 覆盖 50% qc 帧需要的簇（测试） | 这些簇的纯度 | 这些簇占全部帧 | 覆盖 80% 需要的簇 | 纯度 | 占全部帧 |
|---|---|---|---|---|---|---|---|
| v2 FM，τ=100（论文规则） | 52 | **1** | 0.08 | 18% | 1 | 0.08 | 18% |
| v2 FM，τ=17 | 309 | 5 | 0.17 | 5% | 13 | 0.09 | 16% |
| v3 FM，τ=7 | 1732 | 40 | 0.14 | 6% | 205 | 0.07 | 20% |
| v3 FM，τ=30 | 1151 | 11 | 0.12 | 7% | 88 | 0.06 | 22% |

（qc 在测试集的整体比例是 0.017。）

- **论文规则的 τ 下，qc 被一个大簇吞掉**：v2 τ=100 时，82% 的 qc 帧落在同一个簇里。这个簇占全部帧的 19%，纯度只有 6–8%（富集约 5 倍）。它是"近距离"簇，不是 qc 簇。
- **小 τ 时 qc 分散在几十到上百个簇里**，没有"纯 qc 簇"。v3 最纯的单个簇纯度约 0.42（富集 33 倍），但只含 2% 的 qc 帧。覆盖一半 qc 帧的那些簇，纯度只有 0.12–0.17。
- **所以 v3 逐帧检测能做到约 0.45 的精确率，靠的不是某个纯簇，而是"时间上的组合"**：分数在 0.75 s 窗口内平滑，相当于看连续的一串簇。这说明 qc 更像是"簇的序列"，而不是单个簇。
- MM att（v3 τ=3，测试）：覆盖一半 att 帧要 22 个簇，纯度 0.05（整体比例 0.001，富集约 50 倍）。另有 25% 的 att 帧没有状态（审核屏蔽）。
- 训练集排在前面的簇对测试集的头部同样有效（k50 相近），但长尾不同：测试集覆盖 95% 需要几百到上千个簇。

## 6. 和论文的不同

**方法上**

1. **状态变量**：论文用 3D 距离和两个朝向角，并有意去掉了上下距离和俯仰角，因为斑马鱼打斗基本在同一水平面（Fig. S6），俯仰集中在 0 附近（Fig. S7）。青鳉不同：我们的 PCA 中上下距离是第一主成分，所以保留了 Δz。v3 又加了速度，v4 加了绕圈速度、接近速度、转向、弯曲、俯仰。论文把整体转速 φ̇ 只用来解释机动（例如绕圈），没有放进状态；v4 的"绕圈速度"相当于把 φ̇ 放进了状态。
2. **三条鱼**：论文是一对鱼。我们有 F–M1、F–M2、M1–M2 三对，分成 FM（有性别方向）和 MM（对称）两个单元。
3. **不丢帧**：两鱼贴在一起时角度无定义，我们设了单独的 contact 状态；审核屏蔽的帧在打分时当作单独的一类。
4. **行为时段和评估**：论文先用 1 分钟窗口的分布无监督地找出打斗时段，再挑出覆盖 95% 打斗帧的 16 个簇作为机动，之后看机动频率随时间的变化（描述性）。我们用 BORIS 的逐帧标注，在独立的测试视频上评估逐帧检出，并和距离基线比较。论文的"行为"是长达几分钟的打斗时段；我们的 qc（约 1–4 s）和 att（< 0.1 s）短得多，而且罕见得多。
6. **预处理**：论文先插值 ≤ 5 帧的缺口，再用 9 帧（0.09 s）Savitzky-Golay 平滑；v1–v3 没有平滑，v4 补做了两版。
5. **τ**：除了论文规则，另加了 LOEO AUC。

**结果上**

1. **簇太碎**：论文 8000 个微状态、τ = 10 帧（0.1 s）得到 56 个簇。我们在相同的时间尺度下得到 1000 多个簇，只有 v2（2048 个状态、τ = 0.6 s）得到约 50 个。可能的原因：
   - 状态数更多（v1、v3 超过 1 万），而数据量更少：每个单元训练集约 280 万帧，论文共约 1600 万帧；
   - 论文的数据以长时间、高强度的打斗为主（两鱼一直很近），我们的大部分时间是各自游泳，状态分布更散；
   - 论文先做了 9 帧平滑，v1–v3 没有，逐帧抖动会让状态频繁跳格。
2. **行为没有对应的簇**：论文的打斗时段可以由 16 个簇覆盖 95%，而且这些簇能命名为攻击、绕圈等。我们的 qc 在论文规则的 τ 下被一个"近距离"大簇吞掉（纯度 6–8%）；在小 τ 下又分散在几十到上百个簇里（见 5.4）。罕见行为（qc 约 1.6% 的帧，att 约 0.1%）不形成自己的簇。
3. **τ**：论文的 τ = 0.1 s。我们按论文规则选出的 τ 在 v2 是 0.4–0.6 s、v3 是 0.08–0.3 s。att 在 τ ≈ 0.02 s 时最好分开，说明对短行为，论文规则选出的 τ 偏大。
4. **wrap**：只用距离反而比簇更好（wrap 时两鱼贴得非常近，而且有一半以上的帧在审核时被屏蔽）。

## 7. 局限

- 只有两个测试视频，而且和训练是同一批鱼，还没有在新个体上测试。
- K 组和 P 组的标注者使用不同的行为词汇（例如 P 组有很长的 follow），chase 目前算作 unknown，影响 att 的评估。
- FM 的 att 太少（测试集只有 7 个 bout），无法评估。
- 簇数多，难以逐个命名。
